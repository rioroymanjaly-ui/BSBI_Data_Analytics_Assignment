# BSBI MSc Data Analytics Portfolio — Rio Roy

This repository presents two MSc Data Analytics projects completed at the Berlin School of Business and Innovation (BSBI). It contains the submitted reports together with reproducible code, validation assets, and implementation guidance.

## Projects

### 1. [CVAI — Medical Diagnostic Image Segmentation](CVAI_Medical_Image_Segmentation/)

A controlled comparison of compact U-Net and Attention U-Net architectures on Kvasir-SEG, including repeated-seed evaluation and MC-dropout uncertainty analysis.

**Methods:** Python, TensorFlow/Keras, semantic segmentation, repeated-seed evaluation, uncertainty analysis  
**Deliverables:** [Project documentation](CVAI_Medical_Image_Segmentation/README.md) · [Submitted report](CVAI_Medical_Image_Segmentation/report/Rio_Roy_CVAI_Assignment_Final.pdf) · [Experiment notebook](CVAI_Medical_Image_Segmentation/code/Rio_Roy_CVAI_Kvasir_Experiment.ipynb)

### 2. [VSTT — Retail Analytics in Tableau](VSTT_Retail_Tableau/)

A management-focused analysis of Tableau Sample — Superstore, covering sales growth, profitability, customer and product performance, geography, discounting, and shipping context.

**Methods:** Tableau, calculated fields, KPI design, dashboard storytelling, validation checks  
**Deliverables:** [Project documentation](VSTT_Retail_Tableau/README.md) · [Submitted report](VSTT_Retail_Tableau/report/Rio_Roy_VSTT_Assignment_FINAL.pdf) · [Tableau build guide](VSTT_Retail_Tableau/tableau/BUILD_GUIDE.md)
